# 確定申告サマリ生成 Discord Bot — MVP 要件定義

## 1. プロダクト概要

ローカル PC の指定フォルダに置かれた確定申告関連書類（源泉徴収票、経費 CSV、控除証明書等）を
Claude Code が直接読み取り・解析し、Discord 上で自然言語による対話を通じて不足情報を補完。
最終的に e-Tax / 確定申告書等作成コーナーに転記可能な **「確定申告サマリ」** を生成する。

### コンセプト

```
「フォルダにファイルを放り込む → Discord で話す → サマリが出る」
```

### 前提・制約

| 項目 | 内容 |
|------|------|
| 対象申告 | 所得税の確定申告（個人・1名分） |
| 対象年度 | 令和7年分（2025年分）※設定で変更可 |
| 申告種別 | MVP では **白色申告** のみ |
| 利用者スコープ | MVP は単一申告者・単一 Discord ユーザーで運用 |
| 提出 | ユーザーが手動で e-Tax に転記・提出 |
| Bot の役割 | **Discord ↔ Claude Code CLI の中継（税額計算は Claude が Bash 経由で実行）** |
| Claude Code | Max プラン（定額サブスク）を使用。API 従量課金なし |
| 操作方法 | 自然言語 |
| データソース | ローカルフォルダのファイルが主、Discord 上の追加入力が補助 |

## 2. アーキテクチャ

### 2.1 設計思想

**Bot は薄い中継層。読取・対話は Claude Code、税額計算はローカルスクリプトで決定論的に実行。**

Claude Code には以下のツールが組み込み済みのため、自前実装は不要:

- **Read** — PDF・画像・テキスト・CSV を直接読み取り
- **Glob** — ファイル一覧の取得
- **Grep** — ファイル内容の検索
- **Write** — ファイル出力
- **Bash** — ローカル計算スクリプト実行、その他コマンド実行

```
Discord ユーザー
    │
    │ 自然言語メッセージ
    ▼
┌──────────────────────────────┐
│  Discord Bot（中継層）         │
│                               │
│  ・Discord メッセージ受信      │
│  ・claude CLI をサブプロセス起動│
│  ・Claude Code の応答を返送    │
│  ・会話セッション管理          │
└──────────┬───────────────────┘
           │
           │  subprocess: claude --resume <session_id>
           ▼
┌──────────────────────────────┐
│  Claude Code CLI (Max プラン)  │
│                               │
│  組み込みツールで自律的に動作:  │
│  ・Read  → PDF/画像/CSV 読取  │
│  ・Glob  → フォルダスキャン    │
│  ・Write → サマリ出力          │
│  ・Bash  → calc-tax.ts 実行    │
│                               │
│  判断・解釈・質問・生成を担当    │
└──────────────────────────────┘
           │
           ▼
┌──────────────────────────────┐
│  ローカルファイルシステム       │
│                               │
│  ~/tax-docs/<tax_year>/        │
│    ├── data/tax_data.json      │
│    └── output/                 │
│  scripts/calc-tax.ts           │
└──────────────────────────────┘
```

### 2.2 処理の流れ

```
1. ユーザーが Discord で「ファイル読んで」と発言
2. Bot がメッセージを受け取る
3. Bot が claude CLI をサブプロセスとして起動（--resume でセッション維持）
4. Claude Code が自律的にツールを使う:
   - Glob で ~/tax-docs/<tax_year>/ をスキャン
   - Read で各ファイル（PDF・画像・CSV）を読み取り
   - 内容を解釈・構造化
5. Claude Code が応答テキストを返す
6. Bot が応答を Discord に送信
7. ユーザーが「合ってる」「修正して」等と返答 → 2 に戻る
8. ユーザーが「サマリ作って」→ Claude Code が集計・生成・Write で出力
```

### 2.3 役割分担

| 担当 | 責務 |
|------|------|
| **Discord Bot** | メッセージ送受信、`claude` CLI 呼び出し、セッション ID 管理、タイムアウト/再試行 |
| **Claude Code** | ファイル読取、解釈、対話、不足質問、サマリ生成 |
| **税額計算スクリプト** | 固定ロジックで所得税・復興特別所得税を計算し JSON 返却 |

### 2.4 Bot → Claude Code の呼び出し方

```ts
import { execFile } from "node:child_process";
import { promisify } from "node:util";

const execFileAsync = promisify(execFile);

const { stdout } = await execFileAsync(
  "claude",
  ["-p", userMessage, "--resume", sessionId],
  { timeout: 90_000, maxBuffer: 1024 * 1024 }
);
const response = stdout;
```

- `-p` : プロンプトを渡して結果を stdout に出力
- `--resume` : 前回の会話を引き継ぐ（セッション維持）
- MVP は 1 Discord ユーザー運用。実装上は user_id ごとに session_id を保持して混線を防ぐ

## 4. ユーザーストーリー（MVP スコープ）

### US-1: フォルダスキャン・ファイル読み取り

> ユーザーとして、指定フォルダにファイルを置いて「読んで」と言うだけで内容を読み取ってほしい。

- Claude Code が Glob → Read で自律的に読み取り
- 対応フォーマット（Claude Code の Read が対応）:
  - **PDF** — 源泉徴収票、控除証明書等
  - **画像**（JPG/PNG） — 証明書のスキャン・写真
  - **CSV** — 経費一覧、収支表
  - **テキスト / Markdown** — 補足メモ
- フォルダ名・ファイル名からカテゴリを推測
- 読み取り結果を報告し、ユーザーに確認

### US-2: 自然言語での確認・修正・追加

> ユーザーとして、読み取り結果の確認も追加入力もすべて自然言語で行いたい。

- 「合ってる」→ 確定
- 「給与収入は 520万に修正して」→ 修正
- 「名前は山田太郎、住所は東京都渋谷区...」→ 基本情報追加
- 「医療費が年間 12万かかった」→ 控除追加

### US-3: 不足情報の自動検出・質問

> ユーザーとして、何が足りないか教えてほしい。

- Claude Code がサマリ生成に必要な項目をチェックし、不足があれば質問
- 「社会保険料の金額が読み取れませんでした。いくらですか？」
- 「扶養家族はいますか？」

### US-4: 集計・サマリ生成

> ユーザーとして、「サマリ作って」と言うだけでサマリを受け取りたい。

- Claude Code が収集済みデータを構造化し、`npx tsx scripts/calc-tax.ts` を Bash で実行して税額計算
- サマリ文章を生成
- Discord に返却 + Write でファイル出力（txt / json）

### US-5: データの確認

> ユーザーとして、今の登録状況を自然言語で確認したい。

- 「今の状況は？」「何が登録されてる？」で一覧表示
- 「リセットして」で全データクリア（確認あり）

### US-6: 初回オンボーディング

> ユーザーとして、最初に何をすればいいかを迷わず理解したい。

- `/start` で初期ガイドを表示する
- ガイドには「対象年度」「入力フォルダ」「機微情報の注意」を含める
- 必要ならそのまま「スキャン開始」まで案内する

### US-7: 進捗の可視化

> ユーザーとして、申告準備がどこまで進んだかをすぐ把握したい。

- `/status` で「読み取り済み / 未確認 / 不足項目」をチェックリスト表示する
- 不足項目は優先度順に表示する

### US-10: 転記しやすい最終サマリ

> ユーザーとして、e-Tax へ迷わず転記したい。

- サマリ出力に「e-Tax 転記順（1,2,3...）」を付与する
- 各項目に対応する値の出典（source_file またはユーザー入力）を併記する

## 5. システムプロンプト

Bot が Claude Code に渡すシステムプロンプト（CLAUDE.md または `-p` の前文として）:

```
あなたは確定申告サポートアシスタントです。

## 役割
ユーザーの確定申告（指定年度・白色申告）に必要な情報を収集・整理し、
e-Tax に転記可能なサマリを生成します。

## 実行時変数
- TAX_YEAR: 対象年度（例: 2025）
- TAX_DOCS_ROOT: 入力ルート（例: ~/tax-docs）

## 入力フォルダ
${TAX_DOCS_ROOT}/${TAX_YEAR}/ にユーザーの税務書類が格納されています。
推奨構成:
  income/     — 源泉徴収票、報酬明細等
  expenses/   — 経費一覧 CSV、レシート画像等
  deductions/ — 控除証明書等

## できること
- Glob/Read でフォルダ内ファイルを読み取り、内容を解釈する
- PDF・画像・CSV を直接読み取る
- 読み取った内容を構造化して ${TAX_DOCS_ROOT}/${TAX_YEAR}/data/tax_data.json に保存する
- 税額計算が必要なときは `npx tsx scripts/calc-tax.ts` を実行し、結果JSONを利用する
- 不足情報をユーザーに質問する
- サマリを生成して ${TAX_DOCS_ROOT}/${TAX_YEAR}/output/ に出力する

## ルール
- 金額は必ずユーザーに確認してから確定する
- 不明な点は推測せず質問する
- 税額を推測計算しない。必ず `npx tsx scripts/calc-tax.ts` の結果を使う
- 税額の表示時は計算根拠（入力値と式）を併記する
- 税額計算は参考値であることを明示する
- マイナンバーは保存しない
```

## 11. セキュリティ要件

| 項目 | 対応 |
|------|------|
| マイナンバー | 保存しない。e-Tax で直接入力 |
| データ保存先 | ローカル JSON ファイルのみ |
| アクセス制御 | Bot は特定の Discord サーバー / チャンネルのみ |
| 入力フォルダ | ローカルファイルシステムのみ |
| Discord Token | .env で管理、.gitignore に含める |
| 税務書類 | Claude Code（Max プラン）経由で Anthropic クラウドへ送信され処理される |

補足:
- 機微情報を含むため、利用前に Anthropic 側の利用規約・データ保持方針を確認する
- Discord チャンネル閲覧権限を最小化し、ログ保存期間を短く設定する

## 12. 非機能要件（MVP）

- `claude` CLI 呼び出しは 90 秒タイムアウト。超過時は1回だけ自動再試行
- 失敗時は Discord に「再試行可否」と「直近失敗理由」を返す
- Discord メッセージが 2000 文字を超える場合は分割送信
- `/start` `/status` は 3 秒以内に一次応答（受付メッセージ）を返す
- 同時実行は1ジョブまで（直列実行）。処理中の追加入力はキューに積む
- `tax_data.json` 書き込みは一時ファイル経由で原子的に置換する
- 主要イベント（scan/start/end/error）は `logs/bot.log` に記録する
