# 令和7年（2025年）分 税額計算の根拠

このドキュメントは `scripts/calc-tax.ts` および `scripts/tax-rules/2025.ts` で実装している
税額計算ロジックの根拠を、国税庁の公式資料と対応付けてまとめたものである。

---

## 1. 給与所得控除

**ソース:** [No.1410 給与所得控除｜国税庁](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1410.htm)

令和7年度税制改正により、最低保障額が 55万円 → **65万円** に引き上げられた。

| 給与等の収入金額 | 給与所得控除額 |
|---|---|
| 190万円以下 | 65万円 |
| 190万円超 360万円以下 | 収入金額 × 30% + 8万円 |
| 360万円超 660万円以下 | 収入金額 × 20% + 44万円 |
| 660万円超 850万円以下 | 収入金額 × 10% + 110万円 |
| 850万円超 | 195万円（上限） |

**実装:** `scripts/tax-rules/2025.ts` — `calcSalaryDeduction()`

複数の給与所得がある場合は合算収入に対して1回適用し、各エントリに比例按分する（端数は最後のエントリへ）。

**実装:** `scripts/tax-rules/income/salary.ts`

## 2. 基礎控除

**ソース:** [令和７年度税制改正による所得税の基礎控除の見直し等について｜国税庁](https://www.nta.go.jp/users/gensen/2025kiso/index.htm)

令和7年分は「基礎控除の特例」により、合計所得金額 655万円以下の層で上乗せがある。

| 合計所得金額 | 基礎控除額 |
|---|---|
| 132万円以下 | 95万円 |
| 132万円超 336万円以下 | 88万円 |
| 336万円超 489万円以下 | 68万円 |
| 489万円超 655万円以下 | 63万円 |
| 655万円超 2,350万円以下 | 58万円 |
| 2,350万円超 2,400万円以下 | 48万円 |
| 2,400万円超 2,450万円以下 | 32万円 |
| 2,450万円超 2,500万円以下 | 16万円 |
| 2,500万円超 | 0円 |

> 2,350万円超の部分は改正前から変更なし。

**実装:** `scripts/tax-rules/2025.ts` — `calcBasicDeduction()`

## 3. 所得税率（速算表）

**ソース:** [No.2260 所得税の税率｜国税庁](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2260.htm)

令和7年分も変更なし（平成27年分以降共通）。

| 課税される所得金額 | 税率 | 控除額 |
|---|---|---|
| 195万円以下 | 5% | 0円 |
| 195万円超 330万円以下 | 10% | 97,500円 |
| 330万円超 695万円以下 | 20% | 427,500円 |
| 695万円超 900万円以下 | 23% | 636,000円 |
| 900万円超 1,800万円以下 | 33% | 1,536,000円 |
| 1,800万円超 4,000万円以下 | 40% | 2,796,000円 |
| 4,000万円超 | 45% | 4,796,000円 |

計算式: `課税所得金額 × 税率 − 控除額 = 所得税額`

**実装:** `scripts/tax-rules/2025.ts` — `calcIncomeTax()`

## 4. 復興特別所得税

**ソース:** [No.2507 復興特別所得税の申告｜国税庁](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2507.htm)

計算式: `基準所得税額 × 2.1%`（1円未満切捨て）

適用期間: 令和19年分まで。

**実装:** `scripts/calc-tax.ts` — `calculate()` 内

## 5. 一時所得

**ソース:** [No.1490 一時所得｜国税庁](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1490.htm)

計算式:
```
一時所得の金額 = 総収入金額 − 収入を得るために支出した金額 − 特別控除額（最高50万円）
```

課税方法: 一時所得の金額の **1/2** を他の所得と合算して総所得金額を求める。

特別控除 50万円は年間合計に対して1回適用。

**実装:** `scripts/tax-rules/income/temporary.ts`

---

## 6. 雑所得

**ソース:** [No.1500 雑所得｜国税庁](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1500.htm)

計算式:
```
雑所得の金額 = 総収入金額 − 必要経費
```

**実装:** `scripts/tax-rules/income/misc.ts`

## 7. 端数処理

**ソース:** [確定申告の手引き｜国税庁](https://www.nta.go.jp/taxes/shiraberu/shinkoku/tebiki/2025/index.htm)

| 対象 | 端数処理 |
|---|---|

| 所得税額 | 100円未満切捨て |

**実装:** `scripts/tax-rules/2025.ts` — `rounding`
